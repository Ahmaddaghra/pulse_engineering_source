## Review discipline

This is a **design proposal**, not a forecast performance report. Phase 1–1C states are derived from user-provided summaries; no internal raw evidence bundle has been independently checked in this authored version.

Pay particular attention to the distinction between **coverage surge** (panel output) and **public attention** (separate instrument). Neither Google Trends nor social data should be represented as a scientifically sampled measure of public opinion.

## Highest-priority review questions

1. Is an independently owned, rights-compliant publisher panel obtainable?
2. Is `first_seen_at` captured early enough for a useful 24h forecast?
3. Are event identities stable when later evidence forces cluster merges/splits?
4. Is the proposed coverage-surge label construct valid and sufficiently prevalent?
5. Can a clean, paired and untouched evaluation disconfirm predictive lift?
6. Would any editorial decision change given the predicted signal?
7. Can this workflow beat NewsWhip-like existing capabilities in the target niche?
